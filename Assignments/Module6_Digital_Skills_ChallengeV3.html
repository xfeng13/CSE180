1. Device Detective

Find your operating system, memory, and storage.
Checkpoint 1

Follow the instructions for your device, then record what you found.

Where to find it

Windows PC
Settings → System → About
Look for: Windows edition, RAM, device specs.
MacBook
Apple menu → About This Mac
Look for: macOS version, chip, memory, storage.
Cellphone
Settings → About / About phone / General → About
Look for: iOS or Android version, model, storage.

2. Storage Detective

Check storage, clean up safely, and free space.
Checkpoint 2

Open your storage settings, identify the biggest space user, and do one safe cleanup step.

Where to find storage

Windows PC
Settings → System → Storage
Then open Temporary files, Apps, or Cleanup recommendations.
MacBook
Apple menu → System Settings → General → Storage
Review recommendations, Documents, Apps, and Trash.
Cellphone
iPhone: Settings → General → iPhone Storage
Android: Settings → Storage

Safe cleanup ideas

Delete old downloads, remove unused apps, empty Recycle Bin/Trash, clear screenshots, or move photos/videos to cloud storage.

4. AI Explorer: Google Lens Detective

Use Google Lens to identify an object, copy text, or translate.
Checkpoint 4

Google Lens is an AI tool that can see images, read text, and help you search what you are looking at. Try it on your phone or computer and complete the tasks below.

Where to find Google Lens

Windows PC / MacBook
Open lens.google.com in your browser.
Or in Chrome, right-click an image and choose “Search image with Google Lens.”
Android phone
Open the Google app or Google Photos.
Tap the Lens camera icon.
iPhone
Open the Google app or Google Photos.
Tap the Lens icon, or use Lens on a photo in Google Photos.

Try these 3 Lens tasks

1. Identify an object: point Lens at a plant, snack, shoe, or classroom object and see what it finds.
2. Copy text: point Lens at printed text and try copying it into a note or message.
3. Translate text: point Lens at a sign, menu, or label in another language and try the translate feature.

5. Security Guardian

Check and improve your device security settings.
Checkpoint 5

Follow the steps below and complete at least one security improvement if possible.

Where to find security settings

Windows PC
Settings → Privacy & security → Windows Security
Check: Virus & threat protection, Firewall, Windows Update, Sign-in options.
MacBook
System Settings → Privacy & Security
Check: Software Update, FileVault, Password, Touch ID, Find My.
Cellphone
iPhone: Settings → Face ID / Passcode, Privacy & Security, General → Software Update
Android: Settings → Security & privacy, System update, Find My Device

Good security habits

Turn on automatic updates, use a strong passcode or password, enable biometric sign-in if available, and make sure your device can be found or locked remotely.

6. Performance Pro

Learn one safe way to help your device run better.
Checkpoint 6

Check one performance or battery setting and complete one safe improvement.

Where to find performance tools

Windows PC
Task Manager → Startup apps
Settings → System → Power & battery
Settings → System → Storage
MacBook
System Settings → General → Login Items
Activity Monitor to see active apps
System Settings → Battery / Storage
Cellphone
Settings → Battery
Settings → Apps / Background app refresh / Battery usage
Settings → Storage

Safe performance ideas

Close unused apps, remove one startup app, turn on battery saver or low power mode, restart the device, or delete files you no longer need.
